# Magical Knowledge Tree - Artwork Generation Prompts

This document contains highly detailed prompts for generating all necessary artwork assets for the "Magical Knowledge Tree" web application, adhering strictly to the provided specifications for format, style, color palette, age appropriateness, and naming conventions.

---

## Artwork Requirements Overview Recap

- **File Format**: PNG with transparent background (for overlays), JPG for backgrounds
- **Resolution**: 1024x1024px for educational illustrations, 512x512px for UI elements, specific resolutions for main tree assets as noted.
- **Style**: Child-friendly, colorful, cartoon/illustration style, consistent across all assets.
- **Color Palette**: Warm, inviting colors; avoid dark or scary themes.
- **Age Appropriateness**: Suitable for children 5-15 years old.
- **Naming Convention**: `[category]_[domain]_[concept]_[variant].png`
