# Magical Knowledge Tree - Artwork Specifications & Tasks

## Artwork Requirements Overview

**Format Requirements:**

- **File Format**: PNG with transparent background (for overlays), JPG for backgrounds
- **Resolution**: 1024x1024px for educational illustrations, 512x512px for UI elements
- **Style**: Child-friendly, colorful, cartoon/illustration style, consistent across all assets
- **Color Palette**: Warm, inviting colors; avoid dark or scary themes
- **Age Appropriateness**: Suitable for children 5-15 years old

**Naming Convention:**
`[category]_[domain]_[concept]_[variant].png`

Examples:

- `education_science_solar_system_01.png`
- `creature_science_professor_owl_01.png`
- `tree_branch_science_growing_01.png`

---

## MVP Domain Focus

For MVP, we'll focus on **3 core domains**:

1. **Science & Technology** (most popular with kids)
2. **Nature & Environment** (highly visual and relatable)
3. **Math & Logic** (fundamental learning domain)

## Artwork Delivery Specifications

### File Organization

Please organize artwork in the following folder structure:

```
/public/artwork/
  /tree/
    - tree_base_*.png
    - tree_branch_*.png
  /creatures/
    - creature_science_*.png
    - creature_nature_*.png
    - creature_math_*.png
  /educational/
    - education_science_*.png
    - education_nature_*.png
    - education_math_*.png
  /ui/
    - ui_*.png
  /landing/
    - landing_*.png
  /fallback/
    - fallback_*.png
    - error_*.png
```

### Quality Requirements

- **Consistency**: All artwork should maintain consistent style and color palette
- **Child-Safety**: No scary, violent, or inappropriate imagery
- **Accessibility**: High contrast, clear details visible at specified resolutions
- **Scalability**: Artwork should look good at both full size and 50% scale

### Animation Frames

For any animated elements, provide individual frames that can be sequenced:

- Growth animations: 3-5 frames showing progression
- Sparkle effects: 4-6 frames for smooth animation
- Creature movements: 2-3 frames for simple animations
